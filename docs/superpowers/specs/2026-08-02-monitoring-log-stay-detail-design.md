# Alur Simpan Log Monitoring

- Setelah log monitoring berhasil disimpan, petugas tetap berada pada detail kasus tahap Monitoring.
- Kasus terpilih dan daftar kasus diperbarui langsung dari respons Case Service.
- Riwayat log langsung menampilkan entri terbaru dan textarea dikosongkan.
- Notifikasi sukses ditampilkan sebagai toast ringan.
- Registrasi, assessment, intervensi, dan terminasi tetap kembali ke halaman list seperti sebelumnya.
