# Banner Laporan Baru pada Dashboard Petugas

- Banner hanya tampil pada menu Dashboard (`beranda`) dan list mode.
- Banner tidak tampil pada Penanganan Kasus atau Arsip.
- Tombol tutup tersedia di kanan atas dan menyembunyikan banner untuk sesi halaman saat ini.
- Jika jumlah laporan baru meningkat setelah polling, banner ditampilkan kembali.
- Badge jumlah laporan baru di navigasi Penanganan Kasus tetap tersedia.
