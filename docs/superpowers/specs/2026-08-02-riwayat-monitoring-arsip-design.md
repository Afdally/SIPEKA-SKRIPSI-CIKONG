# Riwayat Monitoring pada Arsip Kasus

- Detail kasus berstatus selesai menampilkan Tahap Monitoring di kartu Riwayat Pengisian Tahapan Kasus.
- Seluruh `activity_log` ditampilkan berurutan sebagai timeline read-only.
- Setiap catatan menampilkan tanggal/jam WITA, nama petugas, dan isi perkembangan kasus.
- Jika kasus lama tidak memiliki log, tahap tetap tampil dengan empty state.
- Form tambah log tetap hanya tersedia pada kasus aktif tahap monitoring.
