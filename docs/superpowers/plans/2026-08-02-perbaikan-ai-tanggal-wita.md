# Rencana Perbaikan Analisis dan Tanggal WITA

1. Tambahkan test regresi jenis kekerasan dan batas pergantian hari UTC/WITA.
2. Tambahkan helper konversi waktu aplikasi dan gunakan pada controller analisis.
3. Ubah konfigurasi Nginx agar alamat container di-resolve ulang otomatis.
4. Jalankan test, build/check, restart service, dan uji endpoint dengan kalimat asli.
