# Rencana Implementasi Konfirmasi Pertemuan

1. Tambahkan `metode_pertemuan` pada model kasus dan terima nilainya saat registrasi.
2. Kirim nilai metode pertemuan dari layanan/frontend saat petugas menyimpan registrasi.
3. Tambahkan tombol WhatsApp yang aman dan field konfirmasi metode pada detail laporan.
4. Tampilkan preferensi awal dan hasil konfirmasi sebagai dua informasi berbeda.
5. Jalankan pemeriksaan sintaks backend, lint, dan build frontend.
