# Rencana Implementasi Sistem Visual Admin

1. Buat komponen bersama profil pengguna sidebar di `frontend/ircm-frontend/src/components/dashboard/SidebarUserMenu.jsx`.
2. Ganti profil topbar dan tombol keluar lama pada kedua dashboard dengan komponen baru.
3. Perbarui token, sidebar glass, navigasi, topbar, dropdown, tombol utama, dan responsif di `frontend/ircm-frontend/src/pages/Dashboard.css`.
4. Jalankan lint terarah, unit test frontend, dan build produksi.
5. Tinjau diff untuk memastikan tidak mengganggu perubahan pengguna lain.
